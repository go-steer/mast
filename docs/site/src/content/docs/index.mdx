## Is mast for you? Thirty seconds of honesty

**As of 2026-10-30, the answer is: use [core-agent](https://github.com/go-steer/core-agent).** It is the one harness go-steer maintains; it already runs unattended on a cluster with approval gates, budgets, durable sessions and remote attach; and everything that made mast different — the durable write gate and outbox, the spend ledger, the scheduling lease, workload bundles and specialists, A2A, the monitoring cycle, the AX task-runner deployment — is landing there ([go-steer/core-agent#1411](https://github.com/go-steer/core-agent/issues/1411)). Pick mast only if you already run it and are waiting on a specific port. The cards below describe the job mast was built for, which is now core-agent's job.

## The four pillars

1. **Unattended.** Runs without a human watching: HTTP-triggered workloads, [budget ceilings](/concepts/budgets/), and [approvals](/concepts/approvals/) that wait for an operator instead of failing.
2. **Library-embedded.** Composes as a Go library inside larger services — with a [tested slim-embed guarantee](/quickstart/library-embed/): pay for what you import.
3. **Multi-provider.** Same config switches [models](/concepts/providers/) without code changes — Gemini (with Google Search and URL-context builtins), Claude on the first-party API or Vertex, and offline test models. Your own backend goes in through `mast.Config.Model`, which is [covered by the v1.0 promise](/reference/stability/).
4. **Durable.** Sessions live in SQLite or Postgres and [survive process death](/concepts/durability/) — a paused approval outlives `kill -9` and resumes in a fresh process.

## Nothing changes your cluster without an operator

A specialist that would change something stops before the call fires, shows
the operator the tool and its arguments, and waits — durably, across a
restart. That boundary is structural rather than prompt-held: a specialist
declares whether it may change anything, and mast **refuses to start** a
roster in which a read-only one can reach a mutating tool.
