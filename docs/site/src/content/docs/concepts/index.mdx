The building blocks every mast deployment touches, whether you run the
daemon or embed the library. These pages explain *how the pieces fit and
why they are shaped that way*; the [reference](/reference/workload-bundle/)
section is where the exact fields, flags, and outcomes live.

If you'd rather see it work first, the
[offline quickstart](/quickstart/unattended-triage/) runs the whole loop —
inject, park, `kill -9`, resume — with no credentials in about five
minutes.
